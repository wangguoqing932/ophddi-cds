# Audits

`recomputed/` contains the numbers regenerated from the deposited data and scripts, including `numbers.json`, `revision_r1_stats.json` and the provenance tables.

`r1_5_independent_review/` contains the 30-case independent review record:

- blinded case table and author key
- returned classifications
- scoring script and results
- review form and reviewer instructions

The independent reviewer was a third ophthalmologist, not one of the two original clinician raters and not an author. The result was 14/30 exact (14/28 within the three author classes; kappa 0.271). The record is deposited so the analysis can be checked rather than taken on trust.

Other top-level files are the audit trails for the DDInter denominator, path attribution, Lexicomp comparison, reference verification and the Handling Editor's six points. The BMC-era archive is under `outputs/archive/bmc_submission/` and is historical only.
