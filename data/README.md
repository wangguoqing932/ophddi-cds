# Data

Final registries and evaluation data used by the manuscript:

| path | contents |
|---|---|
| `seed/` | 113 ophthalmic agents, 232 systemic drugs, evidence chunks and interaction records |
| `registry/` | the same final entity registries in the layout expected by the public build scripts |
| `curation/` | entity candidates, rule citations, rule–evidence map, absorption-tier evidence, rule-provenance audit |
| `ddinter/` | DDInter 2.0 severity tables (CC BY-NC-SA 4.0; research reproducibility only) |
| `gold/` | validation and audit case sets with per-case provenance |
| `evidence/` | evidence chunks and interaction records used for retrieval |
| `mock/` | 25 mock pairs for the zero-configuration demo |
| `manifest/` | build manifests and source manifests |
| `predictions/` | baseline and multi-seed prediction records |

The registry-scale result is based on 1,933 registry-matched pairs with a graded DDInter severity. No patient-level data are included. See the repository `LICENSE` for the component licensing split.
