# Submission package (writer phase 7_9)

Target journal: **BMC Bioinformatics**.

| File | Content |
|---|---|
| `manuscript.md` | Assembled manuscript (copy of the deliverable) |
| `cover_letter.md` | Cover letter, written for BMC Bioinformatics |
| `data_availability.md` | Availability of data and materials statement |
| `declarations.md` | Declarations reordered to the journal's mandatory subheadings |
| `highlights.md` | 5 highlight bullets |
| `journal_guidelines_snapshot.md` | Retrieved requirements + automated compliance check |

## Deliberate deviations from the skill defaults

1. **No `submission_pkg.zip`.** The author asked for deliverables to be the manuscript,
   supplementary material, figures and tables only, without a submission archive.
2. **The cover letter is not template-generated.** The skill's default rewrites
   `cover_letter.md` from a template; here the real, journal-specific letter is copied
   in so that template text cannot overwrite it.
3. **The manuscript is not silently restructured.** Journal-required changes (abstract
   subheadings, Background naming, Declarations layout) are reported in the snapshot
   rather than applied, because they alter text the authors have already reviewed.
