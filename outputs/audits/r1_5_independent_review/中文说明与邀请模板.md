# R1-5 独立复核：中文说明与邀请模板

## 给复核心的说明（可直接转发）

**目的**：对 30 对“眼科局部用药 × 全身用药”的分歧病例做一次独立分类，判断系统给出的较低分级是“与局部吸收有限相一致”，还是“缺乏依据的降级”。这是一次匿名的专业意见复核，不涉及患者数据，也不涉及临床操作。

**您需要做的**：打开 `review_form.html`（推荐，浏览器直接打开，自动保存），逐例选择分类并填写理由；如果您更习惯表格，也可以打开 `cases_blinded.csv` 逐行填写：

- `your_class`：从下面 5 个标签中选一个；
- `your_reason`：一句话理由；
- `confidence`：high / medium / low（可选）。

**您能看到**：药物对、参考分级（DDInter）、系统分级、吸收 tier、方向（downgrade / upgrade）。

**您不会看到**：作者的分类、系统的决策路径、匹配的规则 ID。这是为了避免被作者的解释锚定。

## 分类标签

| 标签 | 什么时候用 | 适用于 |
|---|---|---|
| `route_consistent_downgrade` | 系统分级更低，且这个更低与局部滴眼后全身暴露有限相一致；效应可能随暴露下降 | downgrade |
| `unsupported_undergrading` | 系统分级更低，但这个更低缺乏依据：机制不依赖暴露、药物本身高吸收、或低暴露下风险仍存在 | downgrade |
| `system_overgrading` | 系统分级更高，且这个更高缺乏依据 | upgrade |
| `supported_upgrade` | 系统分级更高，且有依据（不属于作者三类，单独报告） | upgrade |
| `uncertain` | 仅凭现有信息无法判断（单独报告，不计入一致率） | 任一方向 |

**注意**：不是所有病例都必须有确定答案。冷门组合如果确实无法判断，请选 `uncertain` 并写原因；这本身是有价值的信息。

## 建议的邀请话术（微信/邮件）

> X 老师您好，我们在做一项眼科局部用药与全身用药相互作用的分级研究，想请您帮忙做一次匿名专业意见复核。共有 30 对药物，您只需要根据药物对、参考分级、系统分级和吸收 tier，判断系统给出的分级是否合理；不需要查病历，也不涉及患者数据。预计 1–2 小时。所有病例已去标识，只有药物名和分级，没有患者信息。如果您愿意，我把 CSV 和一页说明发给您；您填好后回传即可。您的意见会以“独立复核人（眼科/临床药学）”的身份致谢，不公开姓名，除非您同意。

## 操作步骤（课题组）

1. 选一位**非作者**、未参与规则/矩阵/标签构建的眼科医师或临床药师；如能选两位更好。
2. 优先发送 `review_form.html`（离线网页，推荐）；或发送 `cases_blinded.csv` + 上面的说明。**绝对不要发送 `author_key.csv`**。
3. 网页导出的 CSV 或表格回收后，另存为 `cases_blinded_reviewed.csv`，运行：
   ```bash
   python outputs/audits/r1_5_independent_review/analyze_independent_review.py \
     --reviewed outputs/audits/r1_5_independent_review/cases_blinded_reviewed.csv
   ```
4. 结果会给出：30 例一致数、Cohen's κ、混淆矩阵、被改判的病例。
5. 若两位复核人：先各自独立填，再比较；只对分歧病例做一次共识讨论或请第三位裁定。稿件报告“两位独立复核人 + 共识”的结果，并给出两人之间的一致性。
6. 回写：§3.5、Table S2 note、R1 回复第 5 条；重建 clean/marked 版本；重跑 92 项门控。

## 结果怎么解读

- **一致率高**（例如 ≥25/30）：说明作者分类可被独立复核支持；仍要报告具体一致数和 κ，不要说“验证了系统”。
- **一致率低或很多 uncertain**：说明这些冷门组合确实难以裁定；如实报告，并把“专家不确定性”作为限制，而不是硬把病例改成某个类别。
- 无论结果如何，R1-5 的完成标准是“进行了独立复核并报告结果”，不是“必须和作者分类一致”。
